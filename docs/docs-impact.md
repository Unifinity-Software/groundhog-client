# Customer documentation impact

The IDE epic adds project configuration, current-user discovery of Aspire tunnels, and IDE workflows. The public CLI
and Aspire guides in this repository document the client behavior. Help center maintainers should add the
`groundhog.json` schema link and precedence examples from [CLI project configuration](cli.md#project-configuration),
and explain that Aspire owns stopping its agents. No server behavior or private administration is described here.
