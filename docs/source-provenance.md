# Source provenance

This repository starts from a fresh snapshot of the original Groundhog client implementation.
No server source, private git history, deployment configuration, customer data, or unrelated product code
is included. Client source and tests retain their MIT license. The public client API and protocol contract
are maintained here from this snapshot onward.

Included components: Protocol, Agent, CLI, Aspire hosting integration, their behavioral tests,
package-only Aspire quickstart, build metadata, client documentation, and company-approved brand assets.
The Groundhog icon, wordmarks and social preview come from this project's owner-approved brand kit.
The Unifinity wordmark is a company brand asset supplied for this project; its inclusion does not bring
website code, configuration, fonts, or history into this repository.

Validate the proposed tree before publication: scan secrets and private identifiers, inspect all source
and documentation links, build Release, run every client suite, inspect package metadata and symbols,
and verify a consumer that uses packages rather than client project references.
